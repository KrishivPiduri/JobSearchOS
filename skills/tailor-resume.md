# Skill: Tailor a Resume for a Job Posting

## When to use
Every time you apply to a specific role. Never send a generic resume.

## Steps

1. Read the job posting and extract:
   - Required skills and qualifications
   - Preferred/nice-to-have skills
   - Key responsibilities
   - Language and phrases that repeat (these signal what the company cares about)

2. Open `profile/career.md` and identify which bullets, roles, and achievements map to those requirements.

3. Draft the resume:
   - Write a 3-line summary at the top tuned to this specific role and company
   - Include only roles relevant to this position — drop or shrink older/unrelated ones
   - Lead each role with the 2-3 bullets most relevant to this job
   - Cut bullets with no relevance — aim for 4-5 bullets per role max
   - Mirror the job posting's language where accurate (e.g., if they say "roadmap prioritization", use that phrase)

4. Quantify wherever possible — numbers make bullets credible.

5. Save the file as `resumes/[company]-[role].md`

6. Do a final check:
   - Does the summary directly address what this role is asking for?
   - Are the top bullets on each role the strongest match?
   - Is anything in the resume that could be cut without loss?

## Output
`resumes/[company]-[role].md`
