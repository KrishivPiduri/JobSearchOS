# JobSearchOS

A personal job search operating system. Each folder has a specific role — don't mix concerns across them.

## Purpose

Help manage and execute a job search: career positioning, tailored applications, outreach, and interview prep.

## Folder structure

| Folder | Contents |
|---|---|
| `profile/` | Career data: background, target roles, positioning, constraints |
| `skills/` | Reusable workflows, built one at a time |
| `resumes/` | Tailored resume drafts, one per target role or company |
| `outreach/` | Message drafts: cold outreach, follow-ups, referral asks |
| `applications/` | Application tracker and records |
| `interviews/` | Prep notes and post-interview debriefs |

## How to work in this repo

- When drafting anything (resume, message, prep notes), pull from `profile/` for grounding facts.
- Resumes and outreach are tailored per role — never generic.
- `skills/` holds reusable workflows. Add to it when a process is worth repeating.
- `applications/` is the source of truth for what's been sent and where things stand.

## Tone

Professional, concrete, no fluff or buzzwords. Write like a senior person who respects the reader's time.
